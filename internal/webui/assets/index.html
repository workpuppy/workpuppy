说明

这条链路与 login.sh 等价：拿授权 URL → 授权成功 → 写 auths/workbuddy-<uid>.json → 账号池几秒内自动热加载，不需要重启容器。

国际版账号需要先完善注册地区、再领一次性 trial；这些在 login.sh 里由 login save 完成，本页只做「加号」这一步。

要求：config.json 里 admin.enabled=true， 且用网关的 api_key 作为本页密钥。

设置管理密钥

填 config.json 里的 api_key （与 /v1 用的是同一把）。密钥只保存在本浏览器的 localStorage，不会上传到别处。

服务端要求 admin.enabled=true 才会注册 /admin/* 端点。
